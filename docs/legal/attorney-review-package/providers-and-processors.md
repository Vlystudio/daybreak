The minimum packet set covers OpenAI, LogMeal, Supabase database/Auth/Storage,
Vercel, Sentry, first-party analytics, Resend, Web Push, proposed APNs, Oura,
Fitbit, proposed-disabled Garmin, Google Calendar, weather services, Spoonacular,
GroceryTracker, and the absence of a customer-support platform.

Every production provider requires an assigned contract owner, exact product
tier, region/transfer mechanism, retention/training settings, encryption and
subprocessor review, executed DPA/terms if needed, breach-notice review, deletion
support, dated security decision, evidence reference, and tested emergency
disable procedure. Software has not approved or accepted any terms. AI and
processor registries continue to fail closed in production.
