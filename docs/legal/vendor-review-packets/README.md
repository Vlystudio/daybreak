## Owner workflow

1. Route each production or proposed provider packet to legal, privacy, security, and the contract owner.
2. Store confidential agreements outside Git; commit only non-secret evidence references and decisions.
3. Reconcile approved data/regions/retention with the public policies, Apple privacy answers, iOS privacy manifest, deletion inventory, and incident plan.
4. Exercise the emergency-disable procedure.
5. Update both this packet source and the enforcement registry (`processors.json` or `ai-providers.json`) only after approval.
6. Re-run `npm run compliance:generate` and `npm run verify:app-store-sections-1-8`.
